# CareRoute Mobile

Flutter portfolio application for discovering healthcare providers, viewing physician profiles, filtering by specialty/location, saving favorites, and requesting appointments.

## Purpose

CareRoute is designed to demonstrate production-oriented Flutter engineering for a mobile developer role: responsive UI, accessibility, REST API integration, state management, error handling, testing, performance awareness, Git/CI, and Android/iOS release readiness.

This repository is intentionally being built as a real, reviewable portfolio project rather than a tutorial clone.

## Planned stack

- Flutter / Dart
- Riverpod
- Dio
- GoRouter
- Freezed / json_serializable where useful
- flutter_secure_storage
- Local caching/persistence
- Laravel REST API when practical
